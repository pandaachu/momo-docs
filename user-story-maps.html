🗺️ User Story Map 使用者故事地圖

客服系統重構專案 — 需求範圍與優先級規劃

📐 什麼是 User Story Map？

一種視覺化工具，將用戶故事按「用戶旅程」（橫軸）和「發布優先級」（縱軸）排列，幫助團隊對齊「做什麼」和「先做什麼」。

🎯 Release 版本說明

MVP = Minimum Viable Product，最小可行產品，核心必做
R2 = Release 2，第二版，增強功能
R3 = Release 3，第三版，進階優化
1️⃣ 客戶售後服務問題
2️⃣ 指定/變更收送貨日
3️⃣ 客退異常
4️⃣ 行銷活動相關問題
5️⃣ 重大案件

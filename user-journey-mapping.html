📈 情緒曲線

😊 高 😐 中 😫 低
接聽來電 理解問題 查詢資料 嘗試解答 建立商談 轉派結案

😫 痛點

  • 查詢資料 要切換 3-4 個系統，客戶在線等待
  • 嘗試解答 找不到標準答案，怕回答錯誤
  • 建立商談 欄位太多，不知道哪些必填
  • 轉派結案 不確定該派給哪個 T2 組別

✨ 機會點

  • 查詢資料 🎯 整合式客戶檢視頁面
  • 嘗試解答 🎯 智慧知識庫搜尋
  • 建立商談 🎯 簡化必填欄位、智慧預填
  • 轉派結案 🎯 智慧分派建議

📈 情緒曲線

😊 高 😐 中 😫 低
收到案件 檢視內容 補充資訊 處理案件 等待回覆 結案回覆

😫 痛點

  • 收到案件 案件量不均，有時太多處理不完
  • 檢視內容 T1 建的商談資訊不完整
  • 補充資訊 浪費雙方時間，客戶體驗差
  • 等待回覆 等太久會超過 SLA，很焦慮

✨ 機會點

  • 收到案件 🎯 自動分派 + 負載平衡
  • 檢視內容 🎯 T1 建單時強制填寫關鍵欄位
  • 補充資訊 🎯 T1 建單引導問對問題
  • 等待回覆 🎯 內部協作追蹤 + 自動催辦

😫 痛點

  • 再次說明 🎯 案件資訊自動帶入
  • 等待處理 🎯 處理進度主動推播
